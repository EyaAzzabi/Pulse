## Honesty notes for judges

- No invented financial metrics anywhere: every number in the dashboard, forecast,
  simulator and copilot traces back to `backend/app/financial`, `forecasting` or
  `simulations` — see `docs/ARCHITECTURE.md` for the data flow.
- The copilot works with **zero external API keys configured** — it will say so
  (`llm_available: false` in the API response) and still answer using the
  deterministic engine. Setting `LLM_PROVIDER`/`LLM_API_KEY` only changes the
  phrasing, never the underlying figures.
- No real money movement, borrowing, or bank integration exists or is claimed.
- The only "action" the system can execute is drafting and (if `N8N_WEBHOOK_URL`
  is configured) sending an invoice reminder email — always behind explicit
  human approval.
