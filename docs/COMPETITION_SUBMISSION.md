# PULSE AI — Topic E: SME Finance Copilot

**Competition:** Shenzhen International FinTech Competition 2026, International Track. This repository is a submission prototype; competition requirements and acceptance are not independently verified here.

Small businesses can be profitable on paper and still lack cash on payroll day. PULSE joins a dated cash-flow model, a Financial Digital Twin, evidence-based explanations and a human approval workflow in a single financial workspace.

The demonstration company, Northstar Studio, uses synthetic data only. Its future obligations and delayed collections produce a reproducible liquidity risk. A user can simulate a purchase, move collection assumptions or negotiate a hypothetical payment extension and compare calculated cash paths without changing real records.

## Topic E mapping

| Capability | Implementation approach |
| --- | --- |
| Understand SME finances | Persisted transactions, invoices and financial summary |
| Anticipate liquidity risk | Deterministic dated forecast and shortfall detection |
| Explore interventions | Isolated Digital Twin scenario calculations |
| Explain recommendations | Financial evidence with explicitly labeled offline or configured AI mode |
| Responsible action | Proposal, human review, role checks and execution audit |
| Reproducibility | Local setup, synthetic seed, tests and CI |

The distinctive feature is the connection between an explanation, a reproducible calculation, a reversible simulation and an approval record. Financial arithmetic remains outside the language model. No formal lending eligibility, bank offers, investment advice or autonomous financial transfers are claimed.

See FEATURE_STATUS.md for actual checks and remaining gaps. External LLM and automation providers require operator configuration and were not verified against live accounts.
